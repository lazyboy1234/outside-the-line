# Paper figures

Journal SVGs for the research paper. Cream paper, crimson / teal / gold. Source is a `<text>` note on each file. Regenerated by `python3 paper/figures/generate_figures.py`.

| File | Shows | Data source |
|---|---|---|
| `fig1-gates.svg` | Twelve CRZ gates by location and region. Bronx = 0. | `data/derived/crz.json` ← NYC Open Data `t6yz-b64h` |
| `fig2-trucks.svg` | Multi-unit overnight share vs cars (31.8% vs 19.7%). Not a "moved" claim; file has no pre-period. | `data/derived/crz.json` ← `t6yz-b64h` |
| `fig3-did.svg` | Bronx DiD event study + pooled bars with 95% CIs. Cordon tunnels as positive control. | `data/derived/bt.json` ← MTA B&T `ebfx-2m7v` |
| `fig4-canyon.svg` | East 138th H/W by segment. Line at 0.5. Nine open, one tall-narrow. | `data/derived/canyon.json` ← OTI `5zhs-2jue` + Street Tree Census `uvpi-gqnh` |
| `fig5-econ.svg` | PUMA 3710 income / poverty vs city average and CRZ Manhattan (PUMA 3807). | `data/derived/economics.json` ← NFH `r3dx-pew9` + HVI `4mhf-duep` |

`itree.json` is planning-grade context for the 9 vs 1 typology on fig4; it is not a separate figure.
